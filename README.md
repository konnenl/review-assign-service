# Сервис назначения ревьюеров для Pull Request’ов
Cервис, который назначает ревьюеров на PR из команды автора, позволяет выполнять переназначение ревьюверов и получать список PR’ов, назначенных конкретному пользователю, а также управлять командами и активностью пользователей. 

## Запуск проекта
```
git clone https://github.com/konnenl/review-assign-service.git
cd review-assign-service
docker-compose up
```
Сервис будет доступен на порту :8080  

Для окружения используется файл `.env`, который намеренно включен в репозиторий. Он содержит только тестовые данные, необходимые для запуска и удобного тестирования сервиса
