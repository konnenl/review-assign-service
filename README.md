# Сервис назначения ревьюеров для Pull Request’ов
Cервис, который назначает ревьюеров на PR из команды автора, позволяет выполнять переназначение ревьюверов и получать список PR’ов, назначенных конкретному пользователю, а также управлять командами и активностью пользователей. 

## Запуск проекта
```
docker-compose up
```
Сервис будет доступен на порту :8080

## Проблемы и решения
- В OpenAPI поле было указано как `mergedAt` (camelCase), в остальных местах используется `snake_case`, для единообразия выбрано `merged_at`
- В документации не было описано поведение при создании команды, если пользователь уже состоит в другой. Судя по примеру в openapi, пользователь может принадлежать только одной команде (в ответах команда передаётся как строка, а не массив). Поэтому реализовано автоматическое переназначение: при добавлении пользователя в новую команду он закрепляется за новой
- В документации отсутствовали code и message для ошибок, связанных с валидацией, для этого были введены новые значения - code: "VALIDATION_ERROR", message: "invalid request body", "invalid request query"
